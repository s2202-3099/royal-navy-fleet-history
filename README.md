# Royal Navy 1793–1982

イギリス海軍の艦艇数を、帆船時代・移行期・近代海軍・戦後縮小の4時代に分けて年別に追うインタラクティブ図表。

- `index.html` 1ファイルで動作（外部依存は Google Fonts のみ）
- 時代ごとのURL: `#sail` `#transition` `#modern` `#postwar` `#overview`
- ← → キーで時点を移動

## データについて

帆船時代は就役中＋予備役を含み、近代以降は就役艦のみ。分類基準が時代で異なるため、時代をまたぐ比較は傾向を見る程度にとどめること。移行期の精度は±20〜25%。出典はページ下部に記載。
