# Royal Navy 1793–1982

イギリス海軍の艦艇数を、帆船時代・移行期・近代海軍・戦後縮小の4時代に分けて年別に追うインタラクティブ図表。兵員数の推移と、他国海軍との比較も載せています。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 図表本体。`data.json` を読み込んで描画する |
| `data.json` | すべての数字・注記・出典の元データ（ここを直せば図表に反映される） |
| `data.csv` / `personnel.csv` | `data.json` から生成した表。`node tools/make-csv.js` で再生成 |

`index.html` は `fetch('data.json')` を使うため、ファイルを直接ダブルクリックでは開けません。このフォルダで `python3 -m http.server` を実行して `http://localhost:8000` を開くか、GitHub Pages で公開してください。

時代ごとのURL: `#sail` `#transition` `#modern` `#postwar` `#overview` `#rivals` `#data`

## データの扱い

- 帆船時代は就役中＋予備役を含み、近代以降は就役艦のみ。分類基準が時代で異なるため、時代をまたぐ艦艇数の比較は傾向を見る程度にとどめること。
- 出典で確かめられなかった値は `null`（図表では「—」）、艦種の一部しか数えていない下限値は `min` に艦種キーを入れる（図表では「≥」）。
- 出典ごとに確認の度合いを `checked` で持つ。`page`＝本文で数字を確認、`search`＝検索結果の要約で確認し原文は未読、`none`＝元データのままで数字と文献の対応が未整理。
- `none` の数字（元データ）は、Conway's・Jane's などの年版で一つずつ確かめるのが今後の課題。
